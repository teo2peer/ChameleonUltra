# Chameleon Ultra CLI

UV is used for package management. Please consider using uv too. https://docs.astral.sh/uv/

Run the interactive client from `software/script/` with
`uv run python chameleon_cli_main.py`. BLE explorer commands are under `ble ...`;
see [`../docs/ble-audit.md`](../docs/ble-audit.md) for the complete workflow.
